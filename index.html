Siteforge only reaches pages and files your browser is allowed to (CORS-permitted, or retried through the fallback proxy). Login-gated, paywalled, or bot-checked content stays out of reach. CSS and JS are inlined directly into each page's HTML — no loose .js/.css files — so nothing gets flagged by antivirus tools on extraction. Good to know

Runs entirely client-side; nothing you enter leaves your browser except the fetch requests it makes, plus a request to allorigins.win when a file needs the fallback proxy. For a PHP site, only what PHP actually renders (HTML/CSS/JS/images) can ever reach the browser — the .php source itself never leaves the server, for any tool, anywhere. For a React/Vite/Webpack app, the real, working compiled bundle is captured, plus any sibling chunk files it references (a heuristic scan, not a guarantee) — but the original uncompiled .jsx source is only recoverable if the site ships a source map. Respect the terms of any site you extract from — this is for your own projects, backups and learning, not for republishing someone else's work as your own.
